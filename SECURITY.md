# Security Policy

## Supported Version

VariantPriorX is currently an early-stage bioinformatics portfolio project.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Security Issue

If you identify a security issue, please avoid publishing sensitive details in a public GitHub issue.

Report the issue privately to the repository maintainer through an appropriate private contact method available on the maintainer's GitHub profile.

## Sensitive Data

VariantPriorX uses publicly available benchmark genomic data and is not designed to process identifiable clinical patient data.

Do not commit or publish:

- Personally identifiable information.
- Protected health information.
- Authentication credentials.
- API keys or access tokens.
- Private clinical genomic datasets.

## Scope

VariantPriorX is intended for research, education, workflow demonstration, and portfolio use.

It is not a production clinical system and should not be used for clinical diagnosis, treatment decisions, or other medical decision-making.
